# Реестр дефектов

## GJ-P1-01 — оборудование и canonical стеновые сегменты отсутствуют на плане

Воспроизведение: открыть saved квартиру с 13 компонентами/9 маршрутами, перейти Plan. Ожидаются все устройства и участки, фактически отсутствуют маркеры устройств и пропускаются 24 стеновых сегмента (screenshot 13). Причина: painter не рисовал оборудование; projector не разрешал canonical wall host через проверенный порядок BoundaryEdgeId. Исправлены projector и painter; неизвестные edge IDs не угадываются. Regression в plan tests, native результат screenshot 14. Статус: исправлено и визуально подтверждено.

## GJ-P1-02 — диагональный manual сегмент невозможно редактировать

Воспроизведение: соединить щит (3000,1500) с розеткой (3600,800), затем тащить диагональный сегмент в ASSIST. Ожидается изменяемая траектория, фактически ничего не меняется (screenshots 06,08). Подтверждённая причина: moveSegment возвращал исходные точки для диагоналей. Добавлен ортогональный обход через позицию мыши с сохранением концов. Regression проверяет геометрию и якоря; native повтор диагонали после исправления ещё не выполнен. Статус: исправлено в коде, native qualification pending.

## GJ-P1-05 — canonical компонент не виден на развёртке стены

Воспроизведение: выбрать canonical розетку, открыть её W1; inspector содержит компонент, сама поверхность пуста (screenshot 15). Причина: сравнение wall ordinal reference с BoundaryEdgeId reference. Добавлена проверенная CableSurfaceProjection для рисования, hit-test, semantics и нормативного контекста. Неизвестный/удалённый edge отклоняется. Widget regression проверяет конкретную semantics-ноду; native screenshot 16 показывает оборудование и кабель. Статус: исправлено, отображение подтверждено; полный повтор drag/route/persistence pending.

## GJ-P2-03 — ручное AC-соединение не является квалифицированной электрической группой

После создания route-1 сохранено other.generic, нет CircuitBundle, legacy anchorIds пусты. Ожидается однозначное описание электрической среды/группы. Native локальное соединение не выдаётся за полноценную электросхему. Новое редактирование сохраняет существующие durable anchors, но не мигрирует автоматически старую anchorless модель. Статус: открыто, нужен отдельный сценарий доменного назначения групп.

## GJ-P2-04 — тяжёлая фиолетовая линия без объяснения

Обратная связь пользователя; screenshot 13. Ожидается лёгкий вспомогательный слой с объяснением. В editable_spatial_canvas уменьшены ширина/alpha, добавлена подпись потолка, selectedRoute остаётся различимой; screenshot 14. Статус: исправлено.

## GJ-P2-06 — панель прокладки закрывает поверхность

При ручном W1→потолок нижняя панель скрывает часть границы; требуется zoom out для перехода. Причина в раскладке UI, не в геометрической модели. Рекомендация: компактная/сворачиваемая панель. Статус: открыто; отдельное изменение UX.
