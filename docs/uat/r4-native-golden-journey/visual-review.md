# Визуальная проверка

Все изображения — native macOS окно ElecX, не widget render.

| Evidence | Наблюдение |
|---|---|
| 01–02 | Запуск production и демо-план |
| 03–04 | Selection и мышиный drag розетки |
| 05–07 | Physical source/target ports и создание локального соединения |
| 08 | Диагональный сегмент не сдвигается в baseline |
| 09–10 | Перенос подключённой нагрузки и редактирование ортогонального сегмента |
| 11–12 | Reopen и дальнейшее редактирование |
| 13 | Полная квартира: устройства не нарисованы, 24 стеновых участка пропущены |
| 14 | Исправленный план: 13 устройств и 33 участка, лёгкие линии и пояснение цвета |
| 15–16 | Canonical оборудование: было только в inspector, стало видно на стене |

По замечанию пользователя фиолетовый кабель на плане сделан тонким (1.1 logical px) и полупрозрачным (alpha 0.42). Цвет обозначает потолочную поверхность, на плане добавлено «фиолетовый — потолок». Выбранная трасса остаётся яркой и толще (2.6 px), чтобы редактирование было различимо.

Риски UX: высокая нижняя панель ручной прокладки закрывает часть поверхности; для доступа к краю использовалось уменьшение масштаба. Переход W1→потолок начат через настоящий GUI, но завершённый multi-surface маршрут и отсутствие разрывов во всей квартире не подтверждены.
