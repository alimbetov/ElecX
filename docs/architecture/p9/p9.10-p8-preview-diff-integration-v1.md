# P9.10 — P8 Preview / Diff Integration v1

## Goal

Extend the accepted P8 preview/diff presentation so apartment generation is explained semantically before Apply, without changing P8 reserved mutation semantics.

## Non-negotiable lifecycle

```text
selected apartment candidate
→ ApplyApartmentCandidateCommand
→ ReservedProjectMutationCoordinator.preview()
→ exact frozen canonical candidate
→ Apartment preview scene + semantic diff
→ user confirms
→ ReservedProjectMutationCoordinator.commit()
```

Apply MUST commit the exact P8 frozen candidate. No apartment generation, ranking, geometry fitting or identity allocation runs during Apply.

## Required P8 Diff extension

Current P8 diff understands Site/Building/Level well. P9 must add apartment-aware categories:

```text
structuralZone
space
opening
topology/adjacency
```

`ZoneId` and `SpaceId` MUST NOT appear to the user only as generic `other` IDs.

## Human-facing diff semantics

Example:

```text
ADD Apartment zone “Apartment 1”
ADD Living room — 24.3 m²
ADD Bedroom 1 — 14.1 m²
ADD Bedroom 2 — 12.8 m²
ADD Kitchen — 10.7 m²
ADD Bathroom — 5.1 m²
ADD Entrance hall — 6.3 m²
ADD Loggia — 4.2 m²
```

Where useful, field changes include:

```text
SpaceUsage
structural type
area
level ownership
apartment-zone membership
boundary topology summary
opening/adjacency summary
```

Raw boundary edges should not flood the default diff. Low-level topology changes remain available in canonical semantic operations/testing, while the default user view groups them under the affected space/apartment.

## Preview source of truth

The large P9 preview is projected from the exact frozen `ReservedProjectMutationPreview.candidate`, not from the earlier card candidate object. The projector may use provenance/semantic keys to map canonical entities back to apartment room roles, but it must never rerun geometry generation.

## Stale behavior

If `LocalProjectVersion` changes after preview:

```text
Apply disabled
status = stale/blocked
message = project changed; refresh preview
```

Refresh explicitly discards the old frozen reservation and constructs a new preview.

## Cancel invariant

Opening P9 Wizard, generating cards, selecting candidates, entering P8 preview and cancelling MUST leave:

```text
LocalProjectVersion unchanged
Undo stack unchanged
repository unchanged
canonical semantic fingerprint unchanged
```

## Diff sorting

Recommended order:

```text
Apartment zone
Spaces by semantic group/display order
Openings
Grouped topology summary
Other operations
```

Stable semantic sort keys must not depend on entity UUID allocation order.

## Accessibility/i18n

All apartment diff titles/field labels are localized through the same P8 RU/EN resource mechanism. Entity semantics come from enums/typed data; no behavior depends on translated labels.
