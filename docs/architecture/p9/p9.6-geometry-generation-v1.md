# P9.6 — Geometry Generation v1

## Goal

Convert a validated semantic topology draft plus P9.4 area allocation into deterministic rectilinear candidate geometry suitable for preview and later canonical materialization.

## v1 geometry scope

P9 v1 supports:

```text
integer millimetre coordinates
rectilinear/orthogonal polygons
rectangular candidate envelope generated by P9
optional L-shaped spaces formed from deterministic cell unions
shared boundaries with exact coordinate agreement
no holes/voids inside one space boundary
bounded vertex count
```

Explicitly deferred:

```text
arbitrary imported envelope fitting
curved walls
free-form polygon optimization
structural-column solver
furniture-aware packing
AI geometry generation
```

## Layout representation

Use a deterministic slicing/cell grammar rather than direct widget coordinates.

```dart
sealed class LayoutNode {}

final class LayoutSplit extends LayoutNode {
  final SplitAxis axis; // horizontal/vertical
  final List<LayoutNode> children;
  final List<int> weights;
}

final class LayoutSpaceLeaf extends LayoutNode {
  final TopologySpaceSlotKey slotKey;
}
```

A template/seed defines the initial layout tree. P9.4 areas influence split ratios but do not change semantic slot identity.

## Envelope construction

The generator derives an envelope aspect from template/seed guidance and requested area.

Authoritative process:

```text
requested area
→ preferred aspect range
→ deterministic width/height estimate
→ snap to geometry grid
→ distribute residual through split positions
```

Recommended geometry grid:

```text
10 mm
```

Grid resolution is a generator implementation detail and versioned through `generatorVersion`.

## Deterministic split algorithm

For each `LayoutSplit`:

```text
1. compute child target areas from P9.4
2. derive ideal split distances using integer/rational math
3. snap split coordinates to grid
4. distribute rounding residual by stable child order/slot key
5. recurse
```

No random backtracking.

If constraints cannot be satisfied within a bounded number of deterministic alternatives declared by the seed, reject the seed.

## Geometric constraints

Each generated space must satisfy template guidance for:

```text
minimum width
maximum/minimum aspect ratio when declared
positive polygon area
closed non-self-intersecting boundary
no overlap with another interior space
required shared boundary length > 0
```

Candidate interior spaces should tile the intended apartment interior envelope. Balcony/loggia may be represented as explicitly attached exterior cells and must not overlap the interior envelope.

## Canonical-ready boundary model

Candidate geometry uses draft edge keys first, but must be materializable into the existing P7 model:

```text
BoundaryPointMm
ProjectBoundaryEdge
SpaceBoundaryTopology
BoundaryEdgeId
```

P9.6 MUST NOT allocate `BoundaryEdgeId`; P9.11 reserves and maps persistent IDs by deterministic semantic edge slots.

## Shared edge rule

Two adjacent spaces share geometrically equal segment coordinates, but each canonical `SpaceBoundaryTopology` may own its own directed boundary edge identity as required by the current P7 ownership model. The generator must keep an explicit shared-boundary relation so adjacency is not inferred later from floating-point proximity.

## Candidate geometry fingerprint

Fingerprint includes sorted:

```text
space slot key
ordered polygon points in canonical orientation
shared-boundary relation keys
candidate envelope
```

Polygon normalization:

```text
consistent winding
stable start vertex (lexicographically smallest coordinate, deterministic tie)
no redundant collinear vertices unless required for a declared shared-boundary split
```

## Failure modes

```text
geometryInfeasible
minimumWidthViolation
aspectRatioViolation
overlapDetected
openBoundary
selfIntersection
requiredAdjacencyNotRealized
areaToleranceExceeded
```

```text

no overlaps/self-intersections

area tolerance satisfied
```
