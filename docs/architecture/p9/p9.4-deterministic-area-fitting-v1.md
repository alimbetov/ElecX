# P9.4 — Deterministic Area Fitting v1

## Goal

Allocate requested apartment area among semantic space slots without stochastic optimization, floating-point instability or hidden relaxation of template constraints.

P9.4 allocates target areas; P9.6 creates final geometry.

## Units

Authoritative area math uses integer square millimetres:

```text
1 m² = 1,000,000 mm²
```

Weights use integer basis points or integer ratios.

## Input

```text
normalized ApartmentWizardParameters
ApartmentTopologyTemplate
expanded semantic slot set
TopologyAreaProfile
```

Each slot has min/preferred/max area, weight, allocation priority and fixed/near-fixed flag.

## Feasibility

```text
minimumRequired = sum(minArea)
maximumAllowed  = sum(maxArea)
```

Reject target outside this range. Never shrink below min or expand above max.

## Normative algorithm

### 1. Minimum allocation

```text
allocation[slot] = minArea
remaining = targetArea - sum(minArea)
```

### 2. Service/near-fixed allocation

Allocate toward preferred area first by stable `allocationPriority`, then slot key.

### 3. Weighted preferred allocation

Distribute remaining capacity toward preferred area using integer weights and largest-remainder distribution. Remainder ties resolve by stable slot key.

### 4. Weighted max allocation

If area remains, distribute toward max area with the same deterministic rule.

### 5. Final residual

Residual from integer arithmetic is allocated deterministically. Final allocation-layer sum MUST equal requested area exactly.

## No hidden coercion

Never change room count, kitchen mode, balcony count, explicit family or requested area to make a template fit.

## Output

```dart
final class ApartmentAreaAllocation {
  final AreaMm2 requestedArea;
  final Map<TopologySpaceSlotKey, AreaMm2> slotAreas;
  final AreaMm2 residual; // zero on success
  final String allocationFingerprint;
}
```

## Geometry handoff tolerance

P9.4 matches target exactly. P9.6 snapping may introduce a geometric difference. Final candidate accepted only when absolute difference is within:

```text
max(0.25 m², 0.5% of requested area)
```

Otherwise reject the seed. This is a product-quality tolerance, not a statutory requirement.

## Failures

```text
areaBelowTemplateMinimum
areaAboveTemplateMaximum
allocationCapacityExhausted
invalidAreaProfile
nonZeroResidual
```

## Complexity

Target approximately `O(n log n)` for n generated spaces. No exhaustive search.
