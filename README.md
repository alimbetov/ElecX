# ElecX

ElecX is a client-oriented engineering design application for electrical and low-current systems.

The product starts from the engineer's workflow: project -> site -> building -> level -> zone/space -> spatial editor -> engineering design -> review and deliverables.

## Current direction

The first implementation milestone is the spatial editor foundation:

- local 4-digit quick unlock UX;
- project hub;
- project/site/building/level/space hierarchy;
- 2D floor/room editor;
- metric grid and snap;
- per-room local reference frame;
- automatic centerlines/guides;
- architecture prepared for later electrical, LAN, CCTV, ACS and fire-system layers.

Development starts in feature branches; `main` remains the integration branch.
